# About ZéNí

## The venture

ZéNí is a coordination infrastructure venture for the Agentic Web. It ships as three live products in pre-pilot operation:

- **PitStop** — operator command surface. The human side of the loop. Where missions are described, work is observed, evidence is reviewed.
- **SideQuest** — routing and accountability engine. The machine side. Capability discovery, deterministic routing, policy-bound skill leases, signed receipts.
- **ZéNí** — operational trust fabric. The hub. Governance, evidence, readiness, continuity across the venture's products and across any system that wants to coordinate through them.

We are at the very early end of the company's life. The thesis is documented openly (in this repository). The implementation is closed and developed in private repositories under their own access policy.

## The frame

The first principle of ZéNí is that the most valuable work in AI for the next decade will not be building cleverer models. It will be building the **coordination layer** that turns isolated models into accountable, governed, composable agents. That coordination layer is, today, missing — and the venture that builds it well will define the next platform shift.

This is the argument the essays in this repository develop in detail:

- [Agentic AI](AGENTIC_AI.md) — the structural shift from chat to action
- [The Agentic Web](AGENTIC_WEB.md) — what the missing infrastructure layer looks like
- [Model Context Protocol (MCP)](MCP.md) — the open standard that started the unlock
- [Why now, why ZéNí](PIVOTAL_MOMENT.md) — the timing argument and the positioning

## What this repository is, and is not

This is an **editorial** repository. It exists to make the venture's thesis legible to curious visitors — developers, partners, investors — without exposing the implementation. There is no SDK to install, no API to call, no source code to compile here.

If you want to install something, you have come to the wrong repository. If you want to **understand something**, you are in the right place.
