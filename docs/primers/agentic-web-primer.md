# Agentic Web Primer

The Agentic Web is the emerging environment where AI agents, tools, APIs, services, and humans interact through more structured digital workflows.

In the earlier web, people navigated pages.

In the application web, people used software tools.

In the Agentic Web, AI systems may help interpret goals, locate resources, call tools, coordinate steps, and return outcomes.

This creates new design requirements:

- identity
- permissions
- context
- coordination
- oversight
- evidence
- trust

ZeNi is positioned around these requirements.
