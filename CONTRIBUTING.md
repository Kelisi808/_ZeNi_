# Contributing

This public repository is primarily an editorial and knowledge space for ZeNi.

At this time, contributions should focus on:

- improving clarity
- improving public education
- refining glossary terms
- suggesting public-facing explanations
- correcting factual errors in public primers

Do not contribute:

- private implementation details
- secrets
- internal architecture
- proprietary routing logic
- internal product roadmaps
- private system documentation
- private code from the ZeNi, PitStop, or SideQuest products

If a contribution would reveal how the private system works internally, it does not belong here.
