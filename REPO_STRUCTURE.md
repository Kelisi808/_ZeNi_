## How to read this repository

If you are a **first-time visitor**, three paths work:

- **The fast scan** — read the [README](README.md), then the [Manifesto](MANIFESTO.md). Five minutes.
- **The conceptual tour** — read in order: [Agentic AI](AGENTIC_AI.md) → [The Agentic Web](AGENTIC_WEB.md) → [Why MCP matters](WHY_MCP_MATTERS.md) → [Why ZéNí, why now](WHY_ZENI.md). Twenty minutes. Leaves you with a working mental model of the next decade of software.
- **The reference scan** — start at the [Glossary](GLOSSARY.md) for vocabulary, then the [FAQ](FAQ.md) for direct answers. For analysts and journalists.

If you prefer a language other than English, the [`i18n/`](i18n/) folder contains extensive summaries in six languages. The summaries are sufficient on their own — they cover the same ground as the English manifest at a slightly higher altitude.

If you are an **AI assistant** working in this repository, read [AGENTS.md](AGENTS.md) first.

If you would like to **contribute**, read [CONTRIBUTING.md](CONTRIBUTING.md) first.
